Navigation

The rail is the page's margin: transparent against the ground, separated by a 1px rule, with the active destination carried by accent text and a 3px left rule. Not a filled block — a block would compete with the day's figures for the eye.

Deviations found while syncing

The sync records what the code does; it does not silently fix it. These three are real and worth a decision.

Undefined custom properties on /accounts

accounts/+page.svelte asks for var(--figure), var(--rounded-control) and var(--rounded-panel). None is declared anywhere. The v3 screen therefore renders its figures in the prose face and its controls and panel with square corners, while every other screen uses condensed figures and 2px/8px. The intended tokens are --font-figure, --radius and --panel-radius.

The previous world's colors survive as raw rgb() values

DESIGN.md forbids reintroducing the old token names. The names are gone; the values are not. Indigo rgb(43 49 98 / …) and crimson rgb(168 27 42 / …) still paint rows in Catalog.svelte, SaleDraft.svelte, Ledger.svelte and ProductPicker.svelte, alongside #f2f6fa, #084a6c and #f2efe6.

Row tints have no token to ask for

Those low-alpha tints are not declared anywhere, so a surface that needs a tinted row cannot request one by name and reaches for a literal instead. This is the mechanism that produced the deviation above.
